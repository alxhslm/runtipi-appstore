# LM Studio Headless

LM Studio Headless runs an OpenAI-compatible local AI inference server for running GGUF LLMs on your Runtipi home server.

## Features
- **OpenAI Compatible API:** Serves requests on `http://<server-ip>:1234/v1`.
- **Configurable Port:** Port can be customized right from the Runtipi UI.
- **Model Storage:** Models are saved persistently in `/app-data/lm-studio/models`.
